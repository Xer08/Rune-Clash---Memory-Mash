# Rune Clash — Memory Tactics

Juego móvil PWA de memoria + combate RPG.

## Incluye
- Tablero 4×4 con 8 parejas.
- Espada, Escudo, Poción, Trampa y Carga Suprema.
- Tres héroes: Guerrero, Mago y Pícaro.
- Combate por turnos con HP, escudo y carga especial.
- 10 salas con enemigos que escalan +15% por sala.
- Curación del 20% entre salas.
- Una elección de 1 de 3 reliquias después de cada sala, con reliquias repetibles cuando se agota la colección.
- Animaciones de flip, parejas, daño, curación y pantalla.
- Audio sintetizado con Web Audio y vibración háptica.
- PWA instalable y funcionamiento offline después de la primera visita.

## Ejecutar
Abre `index.html` mediante un servidor local o publícalo en GitHub Pages. El Service Worker requiere un contexto seguro (HTTPS) o localhost.


## Créditos de tipografía
La interfaz utiliza **Pixelify Sans**, una tipografía pixel art cargada como webfont. Se aplica de forma global a HUD, botones, diálogos, números, efectos flotantes y textos de combate.
